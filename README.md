# Obsidian vault (Moove Digital and personal projects)
No MTN content goes in here.

## Open in Obsidian
1. `git clone https://github.com/MalcolmGov/obsidian-vault.git`
2. In Obsidian: Open folder as vault, pick the cloned folder. Start at `Home.md`.

## Sync with Obsidian Git
1. Settings > Community plugins > Browse > install "Git" (Vinzent03), enable it.
2. Set auto pull on startup and auto commit-and-sync every 10 minutes.
3. Your Mac needs Git access to GitHub (GitHub Desktop or a credential helper).
